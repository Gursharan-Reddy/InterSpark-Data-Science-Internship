# Data Science Internship Portfolio - Alfido Tech
**Author:** Gursharan 

This repository contains the completed tasks for the Alfido Tech Data Science Internship. The objective of these projects is to demonstrate end-to-end data science skills, including data cleaning, exploratory data analysis (EDA), and machine learning model building.

## 📂 Projects Included

### Task 1: Zomato Dataset Analysis
* **Goal:** Analyze restaurant data to extract insights on ratings, costs, and popular cuisines.
* **Key Skills:** Data Cleaning, Regex, Geospatial plotting, Correlation Analysis, WordClouds.

### Task 2: Loan Approval Prediction
* **Goal:** Build a supervised machine learning model to predict loan approvals based on borrower features.
* **Key Skills:** Handling Class Imbalance (SMOTE), Categorical Encoding, Logistic Regression, Random Forest, ROC-AUC Evaluation.

### Task 3: Instagram Data Analysis
* **Goal:** Analyze an Instagram comments dataset to extract audience engagement trends and text-based insights.
* **Key Skills:** Time-series feature engineering, Missing Data Handling, Text parsing, Seaborn Visualizations.

## 🚀 How to Run
All projects were built using Google Colab. To reproduce the results, click on the `.ipynb` files in this repository and open them in Google Colab. The datasets are imported dynamically via the `kagglehub` library.
